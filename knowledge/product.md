## Strategy:

### Plan A (B2B):
Provide an tool to restaurants to understand item based reviews. Understanding of that will help to adjust sales and marketing strategy. Increase of reviews.

### Plan B (B2C):
Provide an tool for users to leave item based reviews to create a "fair listings" which will help to find desired dish

### Plan C (B2B):
Provide an tool to agencies (Michelin, Falstaff) or existing restaurant sowftwares (r_keeper) as additional features to their existing infrastructure


## Key features:

### User. Raiting
User scan QR and rate displayed disches from 1 to 5. 
Once review is done LLM generates review and ask to leave it on the desired platofrm
User receives X points for each review and proposed to save them by creating account

### User. Profile
User can login and see:
history of his reviews 
total number of points

### Restaurant. Waiter
Can assign dishes from the menu to the table
Can close table review (otherwise closed automatically withing 30 minutes)
Option - can build a table by making photo of the receipt / screen

### Restaurant. Admin
Load and edit menu, if possible sync with internal system
See statistics / reports 
See users and assign roles for his restaurant
